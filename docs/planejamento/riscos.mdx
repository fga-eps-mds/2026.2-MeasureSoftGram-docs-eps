# Gestao de riscos

Riscos identificados pela equipe, com plano de resposta. A tabela deve ser
revisada a cada sprint.

### Legenda

- **Probabilidade / Impacto:** Baixo, Medio, Alto.
- **Resposta:** Evitar, Mitigar, Transferir, Aceitar.
- **Status:** Aberto, Em monitoramento, Materializado, Encerrado.
