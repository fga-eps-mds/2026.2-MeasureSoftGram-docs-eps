## Definicao de pronto (DoD)

Uma tarefa so e considerada concluida quando:

- [ ] O codigo passa nos testes automatizados.
- [ ] Foi revisado por ao menos um outro integrante.
- [ ] A documentacao afetada foi atualizada.
- [ ] Foi integrado a branch principal.
