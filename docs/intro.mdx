# Documentacao da equipe - EPS 2026.2

Este site reune a documentacao produzida pela equipe de **Engenharia de Produto de
Software (EPS)** do semestre 2026.2 no projeto **MeasureSoftGram**.

## O que voce encontra aqui

| Secao | Conteudo |
| --- | --- |
| [Produto](/docs/produto/visao-do-produto) | Visao do produto, arquitetura e repositorios que compoem o sistema. |
| [Diagnostico](/docs/diagnostico) | Estado tecnico do ecossistema levantado na Sprint 1, e o backlog tecnico de 41 itens que saiu dele. |
| [Planejamento](/docs/planejamento) | Metodologia, roadmap do semestre e gestao de riscos. |
| [Sprints](/docs/sprints) | Planejamento, acompanhamento e retrospectiva de cada sprint. |
| [Metricas](/docs/metricas) | Indicadores de processo e de produto acompanhados pela equipe. |
| [Equipe](/docs/equipe) | Integrantes, papeis e politicas de trabalho. |

## Sobre o MeasureSoftGram

O MeasureSoftGram e uma plataforma de medicao e avaliacao de qualidade de
software. Ele coleta metricas de repositorios, aplica um modelo de qualidade
configuravel e apresenta o resultado de forma comparavel ao longo do tempo.

A documentacao **do produto** (como usar, referencia da CLI, componentes) vive em
repositorio proprio: [MeasureSoftGram-Docs](https://fga-eps-mds.github.io/MeasureSoftGram-Docs/).
Este site trata do **trabalho da equipe na disciplina**.

## Como contribuir com esta documentacao

O site e gerado com [Docusaurus](https://docusaurus.io/) a partir dos arquivos
Markdown em `docs/`. Para rodar localmente:

```bash
yarn install
yarn start
```

Cada pagina tem um link **Edit this page** no rodape que leva direto ao arquivo
correspondente no GitHub. Alteracoes na branch `main` sao publicadas
automaticamente pelo workflow do GitHub Pages.
